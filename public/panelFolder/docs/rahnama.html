۱. معرفی قالب

زمانک یک قالب HTML فروشگاهی ایرانی و کاملاً فارسی است که به‌طور تخصصی برای فروشگاه‌های آنلاین ساعت مچی طراحی شده است. این قالب شامل صفحات فروشگاهی، پنل کاربری، فرآیند خرید، وبلاگ و بخش‌های اطلاع‌رسانی می‌باشد و با استفاده از Bootstrap 5 RTL و استایل سفارشی، تجربه‌ای مدرن و حرفه‌ای ارائه می‌دهد.

قالب زمانک به‌صورت استاتیک (HTML/CSS/JS) توسعه یافته و برای استفاده مستقیم، اتصال به بک‌اند (PHP، Node.js، Laravel و...) یا تبدیل به قالب CMS مناسب است.

۲. ویژگی‌های کلیدی

  • ۲۶ صفحه HTML فارسی با چیدمان راست‌به‌چپ (RTL)
  • مگا منو چندستونه برای دسته‌بندی ساعت مردانه، زنانه، هوشمند و برندها
  • اسلایدر اصلی با سه اسلاید تبلیغاتی و بنرهای ویژه
  • کارت محصول با نشان تخفیف، امتیاز، علاقه‌مندی و افزودن به سبد
  • صفحه محصول با گالری تصویر، انتخاب رنگ، مشخصات فنی و نظرات
  • سبد خرید و فرآیند تسویه حساب ۴ مرحله‌ای (آدرس، پرداخت، بررسی، موفقیت)
  • احراز هویت ورود، ثبت‌نام و تأیید OTP
  • پنل کاربری پروفایل، سفارشات، علاقه‌مندی‌ها، بازدیدهای اخیر و آدرس‌ها
  • مقایسه محصولات، شگفت‌انگیزها با تایمر شمارش معکوس
  • مجله وبلاگ با مقالات و صفحه جزئیات
  • پرسش‌های متداول (FAQ) با آکاردئون
  • جستجوی زنده با پیشنهادات
  • طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
  • فونت فارسی Vazirmatn (ایران‌یکان) به‌صورت آفلاین
  • تصاویر واقعی محصول ساعت مردانه، زنانه و هوشمند

۵. نصب و راه‌اندازی

روش ۱ — باز کردن مستقیم

  1. پوشه zamank را از فایل فشرده خارج کنید.
  2. فایل index.html را در مرورگر (Chrome، Edge، Firefox) باز کنید.
  3. تمام لینک‌های داخلی به‌صورت نسبی تنظیم شده‌اند.

روش ۲ — سرور محلی

برای تست دقیق‌تر (به‌ویژه فونت‌ها و مسیرها)، از یک سرور محلی استفاده کنید:

  • VS Code / Cursor: افزونه Live Server
  • PHP: php -S localhost:8000 در پوشه zamank
  • Python: python -m http.server 8000

روش ۳ — آپلود روی هاست

  1. تمام محتویات پوشه zamank را در public_html آپلود کنید.
  2. مطمئن شوید فایل index.html در ریشه دامنه قرار دارد.
  3. برای اتصال فرم‌ها و سبد خرید به بک‌اند، نیاز به توسعه سمت سرور دارید.
توجه: این قالب فرانت‌اند استاتیک است. عملکردهایی مانند ورود واقعی، پرداخت و ثبت سفارش به‌صورت نمایشی (Demo) پیاده‌سازی شده‌اند و برای محیط تولید نیاز به بک‌اند دارند.

۶. سفارشی‌سازی

تغییر نام و برند

  • متن «زمانک» را در فایل‌های HTML جستجو و جایگزین کنید.
  • لوگو در کلاس .header-logo و .footer-logo قرار دارد.
  • عنوان صفحات را در تگ <title> هر فایل تغییر دهید.

تغییر رنگ‌ها

در ابتدای فایل css/styles.css، بخش :root متغیرهای CSS را ویرایش کنید. تمام المان‌ها از این متغیرها استفاده می‌کنند.

افزودن محصول جدید

  1. تصویر محصول را در images/products/ قرار دهید.
  2. یک کارت محصول را از index.html یا search.html کپی کنید.
  3. نام، برند، قیمت، تصویر و لینک را به‌روزرسانی کنید.
  4. برای صفحه اختصاصی، product.html را کپی و محتوا را تغییر دهید.

ویرایش منو و دسته‌بندی

مگا منوها در بخش <nav class="category-nav"> فایل index.html قرار دارند. سه نوع مگا منو موجود است:

  • mega-menu-4col — چهار ستونه (ساعت مردانه)
  • mega-menu-3col — سه ستونه (ساعت زنانه)
  • mega-menu-2col — دو ستونه (ساعت هوشمند)

تغییر فونت

فونت پیش‌فرض Vazirmatn در css/styles.css با @font-face تعریف شده. برای تعویض، فایل‌های woff2 را در پوشه fonts/ قرار دهید و مسیرها را به‌روز کنید.

۹. واکنش‌گرایی

قالب با Grid سیستم Bootstrap 5 و Media Queryهای سفارشی در styles.css برای سه سطح بهینه شده است:

  • موبایل (زیر ۷۶۸px): منوی همبرگری، جستجوی جدا، تب‌های محصول
  • تبلت (۷۶۸–۹۹۲px): چیدمان دو ستونه محصولات
  • دسکتاپ (بالای ۹۹۲px): مگا منو، جستجوی کامل، ۴ ستونه محصول

۱۰. نکات فنی

  • وابستگی‌ها (CDN): Bootstrap 5.3.2 RTL، Bootstrap Icons 1.11.1 — اتصال اینترنت برای بارگذاری اولیه لازم است.
  • مرورگرها: Chrome 90+، Firefox 88+، Safari 14+، Edge 90+
  • کدگذاری: UTF-8 — حتماً فایل‌ها را با این encoding ذخیره کنید.
  • جهت متن: dir="rtl" و lang="fa" در تگ html
  • مسیر تصاویر: از ریشه images/ — از صفحات داخل pages از ../images/

اتصال به بک‌اند (پیشنهادی)

  1. فرم‌های auth را به API ورود/ثبت‌نام متصل کنید.
  2. لیست محصولات را از دیتابیس یا JSON بارگذاری کنید.
  3. سبد خرید را با Session سرور یا JWT مدیریت کنید.
  4. درگاه پرداخت (زرین‌پال، سامان و...) را در checkout-payment پیاده کنید.

۱۱. پشتیبانی و مجوز

قالب زمانک برای استفاده در پروژه‌های شخصی و تجاری فروشگاه ساعت مچی ارائه شده است. بازنشر مجدد قالب به‌صورت خام (Re-distribution) بدون مجوز مجاز نیست.

برای گزارش مشکل یا درخواست سفارشی‌سازی با تیم پشتیبانی تماس بگیرید.
